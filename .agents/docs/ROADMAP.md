# 路線圖

| 階段 | 驗收或依賴 |
| --- | --- |
| 資產與環境 | 固定來源及執行版本，核對六軸鏈、限制與裸臂碰撞和慣量 |
| 固定底座 Foundation | 驗證 SPEC 中的運動、碰撞和停止／重置 |
| 可重現交付 | 固定 headless 入口，保存數值報告、回歸和 Kit 渲染影片 |
| 未來自製末端 | 依實際安裝變換、外形、質量、慣量和 TCP 確認物理接入，再重新驗證相關規格 |

需求與驗收見 [SPEC](SPEC.md)，模型和控制方案見 [DESIGN](DESIGN.md)。本地 `.agents/plans/PLAN.md` 的 §0 維護當前執行與驗證狀態。
