# 研發筆記

記錄過程中重要的原理與經驗，方便之後回顧。

## 2026-11-16

- **J6 是關節，link6 是連桿**

  J6 讓 link6 相對 link5 轉動。前五軸固定、只轉 J6 時，link5 才保持不動。設計固定件時，除了確認能貼合 link6，也要檢查整個轉動範圍內是否碰到 link5；先前的套筒就是在這裡發生干涉。

- **CAD 外形不能直接決定質量與慣量**

  STEP 提供形狀，但不知道材料、列印填充和內部結構。目前固定件含螺絲為 77 g、球拍 170 g，總載荷 247 g；質心與慣量先按各零件均勻分布估算。這是已確認的仿真近似，之後若有實測資料再修正。

- **TCP 是控制球拍用的參考位置與方向**

  我們把 TCP 設在指定拍面的中心，X 沿拍柄朝拍頭，Z 垂直拍面向外。它與機械臂的安裝面不同。FK、IK 和實際球拍姿態回饋必須使用同一套定義，否則即使關節角正確，拍面位置也可能算錯。

- **視覺外形正確，碰撞外形仍可能有問題**

  單一凸包會把厚拍柄與薄拍頭連成略斜的表面，讓正面來球多出側向速度。測試中，整拍凸包產生約 0.023 m/s 的側速；改用原 CAD 靜態表面後，該案例側速為零。M3 再把可動球拍分成拍柄／拍頭兩塊凸包，該案例的出球速度與落點和 CAD 參考一致；原安裝、質量及 TCP 不變。

- **施力前先確認座標系**

  阻力與球的運動方向相反，大小隨速度平方增加。我們用世界座標計算阻力，但本機 Isaac Lab 2.1 的外力接口接受球的局部座標，因此要先做轉換。檢查方法是旋轉球的初始姿態：相同來球速度下，飛行軌跡應保持一致。

- **正常運動要靠驅動或施力，不能直接改位置**

  直接寫入關節角或球的位置，適合初始化與重置。正常運動若也這樣做，就可能跳過慣性、追蹤誤差與碰撞反應。因此手臂透過關節驅動運動，球則交給重力、阻力和接觸力推動。

- **步長收斂不等於實物準確**

  步長越小，仿真計算通常越細，但也越慢。我們比較了 240／480／960 Hz，限定測試中最大落點差約 6.8 mm、出球速度差約 0.6%，已通過門檻。這表示數值結果夠穩定；球拍回彈、摩擦等係數仍未實測校準，不能據此認定真實擊球也同樣準確。

- **讀論文也要核對程式，不能整套照搬**

  PACE 的仿真球使用 3.4 g，預測器卻使用 2.7 g，阻力係數也不同；本專案需要統一參數並獨立驗證。另外，不同次發球的位置資料不能混成一條軌跡。PACE 原本控制人形機器人，移到固定六軸臂時，觀測、動作與獎勵也要重新設計。

- **碰到球，不代表回球成功**

  M3 把手臂和球放進同一場景，按「己方反彈、拍面接觸、過網、對方落桌」判定。保持球拍雖能接到三組來球，但球落回己方，仍須記為失敗。

- **位置可達，也要來得及**

  IK 有解只表示能到那個姿態，還要檢查速度、加速度、反應時間和路徑碰撞。目前通過的是預先就位接球；主動移動和擊球速度需要後續規劃。

- **桌上固定時，要區分安裝接觸和意外碰撞**

  底座直接貼桌面是預期的固定接合，只排除底座／桌面這一對。手臂、固定件和球拍仍不能穿桌。底座外形前後不對稱，所以用外形後緣決定距桌端的位置，不能把底座原點直接放在桌邊。

- **移動底座後，要重新驗證接球姿態**

  固定到桌面後，原本的拍面位置與方向未必仍可達。這次重新求解初始姿態，保留四組來球重新驗證；20項數值與9項單拍檢查通過，仍是三組碰拍後己方落桌、一組漏接。幾何變更前的通過結果不能直接套用。

- **兩塊凸包不等於兩個球拍零件**

  凸包像拉緊薄膜包住外形，會填平凹處。拍柄與拍頭各用一個凸包，可以避免厚柄到薄拍頭之間出現假的斜面；兩塊碰撞形狀仍屬於同一個球拍剛體，不會相對移動。

- **預測要分清碰球之前和之後**

  M4 從當前球的位置和速度預測反彈、最高點、過網與落點，時間從這次觀測開始算，位置都是球心。它不知道未來球拍會怎麼撞球；實測碰拍後，要用新的球速重新預測。桌緣／網邊擦碰目前明確回報不支援。

- **同一個步長，不一定滿足下一階段的精度**

  240Hz通過M2限定物理測試，但M4反彈後落點時間P95誤差約11.9ms，超過10ms。相同案例改480Hz後降到約5.6ms，沒有放寬門檻或調回彈係數；單拍場景因此採480Hz，每秒需要兩倍物理步數。
