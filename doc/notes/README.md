## 筆記不限定用Markdown

- **先讓人看懂。** 文字說明原因；動作用短片；路徑與誤差用圖；需要切換案例、時間或參數時才做HTML互動頁。每個素材要說清它是實測、重播還是示意。
- **同一內容只維護一份。** Markdown或HTML由本頁連結，圖片引用同一檔案；每次完成用既有檔名更新，不累積一串final／v2／latest副本。
- **Git保留小而有用的成果。** 目前M5只需一張代表性路線／落點圖和生成程式；影片、逐幀資料及臨時預覽留本地runs。HTML優先讀取精簡資料或引用現有素材，不內嵌整段影片。正式發布影片時再選擇外部附件或Release，不自動上傳。
- **完成後清理。** 檢查是否仍被引用、有無重複、能否重建；只刪本任務已被替代的預覽與中間產物。原始資料、授權檔及唯一的有效失敗證據保留。
